# Рыбалка: карта мест (v2)

Карта с погодой: тап по карте показывает погоду, точку можно сохранить, есть список точек, описание, тёмная тема и режим без сети.

## Как обновить на GitHub
1. Откройте github.com/TheGreenStudio/fishmap/upload
2. Перетащите ВСЕ файлы из этой папки (старые с теми же именами заменятся).
3. Нажмите Commit changes. Через 1-2 минуты обновится https://thegreenstudio.github.io/fishmap/
4. На телефоне откройте ссылку два раза: первый раз скачается новая версия, второй раз она включится.

## Файлы
index.html, app.css, app.js: приложение. sw.js: работа без интернета. leaflet.*: библиотека карты. inter-*.woff2: шрифт. spots.json: общие точки (пока пусто).
