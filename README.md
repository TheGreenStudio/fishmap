# Рыбалка: карта мест

Интерактивная карта с погодой, работает как приложение и частично без интернета.

## Как выложить бесплатно (GitHub Pages)
1. На github.com создайте репозиторий, например `fishmap` (Public).
2. Add file → Upload files → перетащите ВСЕ файлы из архива → Commit.
3. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
4. Через 1-2 минуты ссылка будет `https://ВАШ-ЛОГИН.github.io/fishmap/`. Её вставьте в закреп группы.

## Как пользоваться
- Откройте ссылку в Chrome (не во встроенном браузере Telegram) → меню ⋮ → «Добавить на главный экран».
- «＋ Точка» → тап по карте → название. Тап по точке показывает погоду.
- «✈️ В Telegram» отправляет точку в чат. Друзья нажимают на ссылку и добавляют её себе.
- Меню ⋯ → «Сохранить карту для офлайна» (дома по Wi-Fi). Погода без сети показывается из последнего сохранения.

## Общие точки для всех
Общие точки лежат в файле `spots.json` (поле `spots`). Формат:
`{"id":"bow1","name":"Bow River, мост","lat":51.03,"lon":-114.06,"note":"парковка рядом"}`
Отредактируйте файл на GitHub, и точка появится у всех.
